# Gibeon-Client
The Gibeon Client is a free, Fabric-based client for Minecraft, designed for DonutSMP. Compatible with the latest versions of miencraft, Gibeon offers 78 powerful modules that rival the capabilities of Meteor Client, providing players with a comprehensive suite of tools for automation, PvP dominance, and world exploration.

Key Features
·PvP Arsenal: Dominate combat with modules like KillAura, CrystalAura, AnchorAura, Aim Assist (bypassing Grim AC), and BedAura. 
·Automation & Utility: Streamline gameplay with Auto-Sell, Auction Sniping, Tree Farming, Auto Replenish, and Emergency Seller. 
·ESP & Detection: Gain a strategic edge with X-Ray, Chunk Finder, Invis ESP, Block Notifier, and Region Map for locating resources and players.
·Mobility & Exploration: Includes Fly, NoFall, NoClip, Auto Walk, and integrated Baritone pathfinding for effortless navigation. 


# Installation
 

1. Install Fabric Loader and the Gibeon Client .jar file.

 

2. Place the .jar file in .minecraft/mods folder.

 

3. Launch Minecraft and press Right Shift to open the GUI.

 

Note: If you already have the Fabric Loader then you do not need to redownload it unless you have an incompatible version.
